# kernel 语义标准

## 职责

`kernel` 是 L0 语义基础 crate，统一定义错误分类和组件生命周期信号。

## 范围

- `error`：不透明错误值、错误类别及错误结果类型。
- `lifecycle`：组件状态、关停信号、守卫和生命周期错误。

本 crate 不承担配置、日志、网络、异步运行时、依赖注入、持久化或业务逻辑。

## 兼容要求

- 时间类型、时钟和精度合同由独立 `temporal` 提供；本 crate 不保留时间公开面或兼容 re-export，二者互不依赖。
- `XError::retry_after` 和关停等待继续使用标准库 `Duration`，不依赖业务时间类型。
- 关停信号只能触发一次，可由多个消费者观察，不可逆。
- 错误分类表示调用方的处理方式，不暴露具体实现类型作为契约。
- 禁止 `unsafe`；公开 API 变更须同步更新 [`API.md`](API.md)。
